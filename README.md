# BrickL

Learn simple engineering with Technic-style bricks. For kids 8+, in English and German.

BrickL is not made by, sponsored by or connected to the LEGO Group.

## What's here (v0.2)
- Lesson map (3 tiers: Basics, Mechanisms, Machines). Lessons 1–3 are playable (Fast gears, Strong gears, Flip it); the rest show "Coming soon".
- Each lesson has 3 steps: Idea → Play (drag parts, turn gears, motor, hints) → Build (parts check, 6 steps, real test).
- English and German. Progress is saved in the browser only. No accounts, no tracking, fonts are hosted here.

## Run locally
Open `index.html` through any static server, e.g. `python3 -m http.server`.
